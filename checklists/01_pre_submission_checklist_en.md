Pre submission checklist
Manuscript Title fits the journal scope. Word count within limits. Abstract follows the journal format. Keywords included. All sections complete and ordered correctly.
Ethics and declarations Conflict of interest statement included. Funding statement included. AI assistance statement included, if applicable. Ethics approval included, if applicable.
References Style matches journal requirements. All in text citations appear in the reference list. DOIs included when available.
Submission package Main manuscript prepared. Anonymous version prepared, if required. Tables and figures prepared as required. Cover letter prepared.
