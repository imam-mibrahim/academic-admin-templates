Academic Admin Templates
Overview A public repository of academic administration templates for university staff. Arabic and English versions.
What you will find Email templates. Memos and circulars. Committee agendas and minutes. Journal and peer review communication. Basic forms and checklists.
Folder structure templates emails en ar memos en ar minutes en ar docs
How to use Open any file. Replace placeholders in brackets. Keep names and sensitive data out of the public repo.
Placeholders Use these fields across all templates. [NAME] [TITLE] [DEPARTMENT] [UNIVERSITY] [DATE] [REFERENCE_NO] [EMAIL] [PHONE] [ATTACHMENT]
